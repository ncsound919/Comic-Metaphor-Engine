### Phase 3: Metaphor Engine 🧠

**Input**: User topic + format + tone

**Processes**:
1. Analyze topic → extract domain, tension, target emotion
2. Query index for matching protocols
3. Select best protocol based on fit
4. Build `MetaphorMapping` object:
   - Map real-world concepts to comic elements
   - Generate beat structure
   - Assign narrative pattern
5. Score mapping using codex adapter

**Outputs**:
- `MetaphorMapping` objects with codex scores

**API**:
```python
engine = MetaphorEngine(index, codex_adapter)
mapping = engine.generate_mapping(
    topic="startup founder burnout",
    format=FormatType.PODCAST_MONOLOGUE,
    tone=ToneType.HOPEFUL,
    constraints={"avoid_topics": ["medication"]}
)
# mapping.trueness_score, mapping.flow_score, etc.
```

**Success Criteria**:
- ✓ Topic analysis extracts key concepts
- ✓ Protocol selection makes sense
- ✓ Mappings generated with explanations
- ✓ Codex scores computed (Trueness, Flow, PCS, RPS, CU)
- ✓ Test suite passes: `pytest tests/test_metaphor_engine.py`

**Key Modules**: 
- `engine/metaphor_engine.py`
- `engine/codex_adapter.py` (wraps existing `codex_engine.py`)

### Phase 4: Narrative Generation 📝

**Processes**:
1. Generate outline with beats (3-5 sections)
2. Format-specific templates:
   - **Podcast**: Hook → 3-5 beats → Conclusion
   - **Marketing**: Subject → Pain → Solution (metaphor) → CTA
   - **Dialogue**: Setup → Conflict → Resolution
3. Generate full script content
4. Generate plain-language explanations

**Outputs**:
- `NarrativeOutline` objects
- `NarrativeOutput` objects (full scripts)
- `Explanation` objects

**API**:
```python
generator = NarrativeGenerator()

script = generator.generate_script(outline, context)

explainer = MetaphorExplainer()
explanation = explainer.explain_mapping(mapping, audience="business", tone=ToneType.HOPEFUL)
```

**Success Criteria**:
- ✓ Outlines have 3-5 beats
- ✓ Scripts meet word count targets (±20%)
- ✓ Explanations include key takeaways + action items
- ✓ Sample outputs saved to `output/`

**Key Modules**:

## 📚 Key Concepts

### Protocols
**Protocols** are the core unit of the metaphor system. Each protocol represents a complete storyline pattern that maps to business/life situations.

The 4 initial protocols:
1. **Armor Wars**: IP proliferation, dual-use dilemma → *Ownership risk*
2. **Secret Invasion**: Insider threats, identity spoofing → *Identity risk*
3. **Days of Future Past**: Over-optimization, algorithmic control → *Control risk*
4. **Planet Hulk**: Externalization, blowback → *Avoidance risk*

### Dimensions (D1-D4)
Each protocol analyzed through 4 lenses:
- **D1 (Bio/Internal)**: Psychological, evolutionary, human factors
- **D2 (Tech/External)**: Tools, systems, technical mechanisms
- **D3 (Eco/Resources)**: Economic costs, resource constraints
- **D4 (Cosmic/Limits)**: Physical laws, entropy, irreversibility

### TAP Metrics
**TAP** = "Top 10 Aspects Priority" — weighted scoring across:
1-10 custom metrics defined in IHS CSVs (e.g., readiness, alignment, resource availability, etc.)

### Codex Scores
From `codex_engine.py`:
- **Trueness**: Signal-to-baggage ratio (A / (B+N))
- **Tap10**: Weighted effectiveness of 10 levers
- **Flow**: Readiness × inverse drag × resources
- **PCS**: Partner/protocol fit
- **RPS**: Rollout priority after risk adjustment
- **CU**: Deliverable capacity
